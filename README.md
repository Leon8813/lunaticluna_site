# 疯人月 · Lunatic Luna

东方Project同人桌游社团官方网站

**域名**: [lunaticluna.cn](https://lunaticluna.cn)

## 技术栈

- 纯静态 HTML + CSS + JS
- 部署于 GitHub Pages + 自定义域名

## 目录结构

```
├── index.html      # 首页
├── games.html      # 桌游作品展示
├── rules.html      # 规则书下载
├── about.html      # 关于社团
├── css/style.css   # 样式
├── js/main.js      # 交互
├── assets/         # 图片素材
├── rules-pdf/      # 规则书 PDF
└── favicon.svg     # 网站图标
```

## 开发

直接编辑 HTML/CSS/JS 文件，`git push` 即可部署。
